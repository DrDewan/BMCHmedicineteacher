# Product Overview

## Purpose
BMCH Medicine Education is the internal clinical teaching workspace for the Department of Medicine, Bangladesh Medical College Hospital. It is designed primarily for registrars/faculty teaching final-year MBBS students.

It is not a general LMS. Its product loop is:

**STORE → FIND → SHOW → TEACH → QUESTION → PRACTISE**

## Core value
A department resource should be reusable. A PDF can produce teaching questions; an X-ray can become a presentation slide and a practice item; a case can be used in class, viva and revision; a procedure can combine images, steps and questions.

## Core modules
- Clinical Cases
- Teaching Materials
- Clinical Images
- X-Rays
- ECG
- Investigations
- Procedures
- Question Bank
- Guidelines
- Practice Round
- Upload / Resource Library
- Viewers
- Native Presentation Builder
- AI-assisted Question Generation

## Product principles
1. Homepage simplicity is a constraint, not a temporary design.
2. Powerful tools appear after a resource/category is opened.
3. Teaching-mode interfaces remove administrative clutter.
4. Native clinical content is structured, not just file storage.
5. AI assists content creation but does not bypass human medical review.
6. The data model should allow future BMCH departments without rewriting the platform.

## Primary users
### Administrator
Manages users, categories, resources, approvals and system settings.

### Registrar / Faculty Editor
Finds material, uploads resources, teaches from viewers, creates structured content/presentations, generates and reviews questions.

### Student / Viewer
Views approved student-visible material and completes practice where enabled.

## Initial success definition
A registrar should be able to find a resource, display it full-screen and begin teaching within approximately one minute. They should also be able to upload new material, create a teaching deck, generate reviewable questions from source material and run a mixed 10-question class practice round.
