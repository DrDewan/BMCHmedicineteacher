# Viewers

## Common viewer requirements
Back to library, clear title, fullscreen, keyboard support, original/source metadata where appropriate, responsive display, teaching mode with reduced chrome.

## PDF Viewer
PDF.js. V1: thumbnails, previous/next, page input, zoom, fit width/page, fullscreen, original download. Later: search, rotate, annotations, AI selected-page actions.

## Slide Viewer
For PPTX preview derivatives and BMCH-native presentations. Thumbnail rail, active slide, previous/next, fullscreen. Original PPTX download remains available when applicable.

## Image Viewer
Zoom, pan, next/previous, thumbnail strip, fullscreen, source/licence metadata.

## X-Ray Viewer
Image viewer plus hide/reveal interpretation. Later brightness, contrast, invert and reset. It is a teaching tool, not a diagnostic radiology workstation.

## ECG Viewer
Large zoom/pan view plus optional structured interpretation: rate, rhythm, axis, P, PR, QRS, ST/T, diagnosis, clinical significance.

## Case Viewer
Progressive stages: presentation, vitals, focused history, examination, investigations, differential, diagnosis, management, teaching points/questions.

## Investigation Viewer
Clinical context → result/table/image → learner prompt → reveal interpretation → differential → next step/clinical implication.

## Procedure Viewer
Overview, indications, contraindications/safety, equipment, preparation, illustrated steps, complications, aftercare, common errors, viva prompts.

## Teaching mode
Full-screen/projector-first with minimal controls and no metadata/editing clutter. Keyboard: arrows for navigation; F/fullscreen where supported; Esc exits fullscreen.
