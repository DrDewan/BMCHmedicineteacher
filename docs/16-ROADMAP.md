# Roadmap

## Phase 0 — Documentation and foundation
Repository contract, Next.js/TypeScript/Tailwind, deployment-ready shell, environment validation.

## Phase 1 — Supabase and Resource Library
Auth/profile roles, categories/resources/version schema, private storage, upload, metadata edit/rename, soft delete/restore, search/filter.

## Phase 2 — Viewers and document processing
PDF.js viewer, image/X-ray/ECG viewers, Document Worker, PPTX/DOCX preview conversion, slide/page thumbnails/text.

## Phase 3 — Native structured teaching content
Case, investigation and procedure editors/viewers with images and progressive reveal.

## Phase 4 — Presentation Builder
Structured slides, reusable resource insertion, reorder/autosave, preview/presenter, PPTX export.

## Phase 5 — AI Question Generation
AIProvider, source selection/page ranges, structured output, review/approval/provenance.

## Phase 6 — Practice Round
Approved question selection, live teaching mode, student mode, mixed rounds and basic results.

## Phase 7 — AI Presentation Assistant
Resource retrieval, outline generation and draft slide generation with faculty review.

## Later expansion
Additional BMCH departments, OSCE, video, journal club/grand-round archive, student analytics, offline/PWA support and institutional SSO.

## Explicitly deferred
Full PowerPoint clone, complex LMS, attendance/calendar/messaging, collaborative editing and diagnostic DICOM workstation features.
