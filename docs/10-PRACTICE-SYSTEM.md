# Practice System

## Purpose
A separate homepage tile provides short mixed teaching/revision rounds from the approved BMCH question bank.

## Default round
10 questions with deliberate variety rather than 10 text MCQs. Target mix may include case, X-ray, ECG, clinical image, investigation, procedure, teaching material and wildcard items.

## Modes
### Live Teaching Mode
Registrar projects the question, students respond verbally, registrar reveals the answer/explanation. Student authentication is unnecessary.

### Student Mode
Student selects/enters an answer; system scores supported formats, reveals explanation according to configuration and records results.

## Setup
Question count 5/10/20; category toggles; topic filter; difficulty; mixed/default mode.

## Selection rules
Use only approved questions. Avoid immediate repeats within a session. Prefer category diversity when enough inventory exists. If a requested category lacks questions, degrade gracefully and explain rather than fail.

## Results
Score plus simple category/topic breakdown. Early releases do not need mastery analytics.

## Persistence
Store session settings, chosen question IDs/order, answers, correctness and completion timestamps. Anonymous/live sessions may omit user ID.
